# Universal Roblox Tool

This repository contains a collection of versatile Roblox scripts designed to enhance gameplay across various Roblox games. The scripts include features such as player movement, chat filtering, leaderboard creation, health regeneration, and team management. Each script is modular and can be easily integrated into any Roblox game.

## Install

1. Clone the repository to your local machine using the following command:
   ```bash
   git clone https://github.com/yourusername/universal-roblox-tool.git
   ```
2. Open the cloned repository in Roblox Studio.
3. Copy the desired script from the `src` folder.
4. Paste the script into the appropriate location within your Roblox game hierarchy.

## Use

1. **PlayerMovement.server.lua**: Place this script in the ServerScriptService to increase the player's walk speed when they jump.
2. **ChatFilter.server.lua**: Place this script in the ServerScriptService to filter out bad words in the chat.
3. **Leaderboard.server.lua**: Place this script in the ServerScriptService to create a leaderboard for player scores.
4. **HealthRegen.server.lua**: Place this script in the ServerScriptService to regenerate the player's health over time.
5. **TeamManager.server.lua**: Place this script in the ServerScriptService to randomly assign players to teams.
